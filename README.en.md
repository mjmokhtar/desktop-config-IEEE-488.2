# 🐍 Python Project

This project is written in **Python**.  
The guide below explains how to run this code in your local environment.

---

## 🚀 Requirements
Make sure you have installed:
- [Python 3.8+](https://www.python.org/downloads/)
- `pip` (usually installed together with Python)
- Git (optional, for cloning the repository)

---

## 🧱 1. Clone the Repository
Clone this repository to your local computer:

```bash
git clone https://github.com/mjmokhtar/desktop-config-esp32
cd desktop-config-esp32
```

---

## 🧪 2. Create a Virtual Environment

Create a *virtual environment* (recommended so dependencies stay isolated):

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 📦 3. Install Dependencies

Make sure you are inside the virtual environment, then run:

```bash
pip install -r requirements.txt
```

> The `requirements.txt` file contains all the Python packages this project needs.

---

## ▶️ 4. Run the Program

Once installation is finished, run the main application:

```bash
python main.py
```

Or, if you are using macOS/Linux with Python 3:

```bash
python3 main.py
```

![image](image/image.png)

---

## 🧰 5. (Optional) Deactivate the Virtual Environment

When you are done, you can leave the virtual environment with:

```bash
deactivate
```
